# Sales Prediction Using Linear Regression

## Overview

This project analyzes advertising expenditure data to understand its relationship with product sales and uses Multiple Linear Regression to predict sales based on TV, Radio, and Newspaper advertising.

## Objective

* Analyze advertising expenditure and sales
* Examine correlations between advertising channels and sales
* Identify the advertising medium with the highest impact on sales
* Build a Linear Regression model to predict sales
* Compare model performance with normalized data

## Work Done

* Data analysis and preprocessing
* Exploratory Data Analysis (EDA)
* Correlation analysis between advertising expenditure and sales
* Built a Multiple Linear Regression model
* Evaluated the model using Mean Squared Error (MSE)
* Compared predictions using all predictors with Radio and Newspaper only
* Predicted sales for a new advertising budget

## Tools & Technologies

* Python
* pandas, numpy
* matplotlib
* scikit-learn

## Key Insights

* TV advertising has the strongest relationship with sales
* Radio has a moderate relationship with sales
* Newspaper has a relatively weak relationship with sales
* Using TV, Radio, and Newspaper together provides a basis for sales prediction
* Normalization has little effect on Linear Regression performance in this dataset

* Learned correlation analysis and data visualization
* Learned to build and evaluate a Multiple Linear Regression model
* Understood how advertising expenditure can be used for sales prediction
