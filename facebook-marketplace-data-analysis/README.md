# Facebook Marketplace Data Analysis

## Overview

This project analyzes the Facebook Live Sellers dataset to understand user engagement patterns and identify factors influencing interactions such as reactions, comments, and shares.

## Objective

* Analyze engagement metrics across different types of posts
* Understand the impact of posting time on user interaction
* Identify relationships between reactions, comments, and shares
* Apply clustering techniques to group posts based on engagement

## Work Done

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Visualization of engagement trends across post types
* Correlation analysis between engagement metrics
* Applied K-Means clustering to segment posts based on performance

## Tools & Technologies

* Python
* pandas, numpy
* matplotlib, seaborn
* scikit-learn

## Key Insights

* Video posts generally receive higher engagement compared to other types
* Reactions are strongly correlated with comments and shares
* Posting time significantly affects user interaction levels
* Clustering reveals distinct groups of low, medium, and high engagement posts

## Learning Outcome

* Gained experience in analyzing social media datasets
* Understood engagement patterns and content performance
* Learned application of K-Means clustering (unsupervised ML)
* Improved data visualization and interpretation skills

## Note

This project was completed as part of foundational data science training and focuses on combining data analysis with basic machine learning techniques.
